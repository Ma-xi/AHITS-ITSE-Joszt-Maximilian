## Installation der VMs

- USB Stick einstecken
- Alle Datein auf den lokalen Rechner kopieren
- Alle extrahieren

Aschließend den VMware Workstation Player öffnen und dort auf Virtuelle Maschine öffnen drücken und beide Auswählen.

---

## Einstellung von Kali Linux und VS Code

Als erstes sich mit dem Passwort und dem Benutzer `kali` anmelden.

Ein Terminal öffnen und anschließend das Tastaturlayout auf deutsch ändern mit:

```sh
setxkbmap de

```

### VS Code

Ausfürhen der Befehle um VS Code zu installieren:

```sh
wget -O vscode.deb "https://code.visualstudio.com/sha/download?build=stable&os=linux-deb-x64"
```

```sh
sudo apt install ./vscode.deb
```

Danach überprüfen ob es geklappt hat mit:

```sh
code --version
```

richtige Ausgabe:

```sh
1.141.0
2a59476c9bfcb90b3ddc372c36762471b7dfad1c
x64

```

### Verbinden mit Github

Diese 2 befehle im Terminal ausführen um die 2 Informationen zu verbinden:

```sh
git config --global user.name "Jon Doe"
git config --global user.email "deine@email.at"
```

Nur den `Namen` und die `Email` auf seine eigene ändern.

Danach entweder ein neues Repository erstellen oder einen Ordner im bereits bestehenden. Im Repository auf die Startseite wechseln und den Link oben kopieren und diesen Befehl in der VM ausführen:

```sh
git clone <GitHub Repo Link>
```

Hier dann nur den Link nach `clone` einfügen.

Um das zu testen ein neue File erstellen z.B. Test und auf der linken Seite auf `Source Control` gehen und dann commiten und syncen

Dortkommen noch 2 Fenster einmal muss man `always` auswählen und einmal `ok dont show again` und als letztes muss man sich noch einmal mit seinem Github Account anmelden.

Um zu Überprüfen ob es jetzt wirklich geht einfach einmal sein Github neuladen.

## Metasploitable

Nach dem öffnen sich anmelden mit dem Benutzer und Passwort `msfadmin`. 

Danach nur noch das Tastatur Layout auf deutsch ändern mit:

```sh
sudo loadkeys de
```

## Pingen und Herunterfahren

Auf der einen VM die IP herausfinden mit:

```sh
ifconfig eth0
```

Danch auf der anderen diese Pingen mit:

```sh
ping (ipadresse)
```

Um am Ende beide herunterzufahren einfach diesen Befehl ausführen:

```sh
sudo shutdown -h now
```
