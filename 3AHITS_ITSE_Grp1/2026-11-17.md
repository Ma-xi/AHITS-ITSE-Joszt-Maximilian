Den Hashwert erhält man danach mit `openssl` und der Funktion `dgst`

## Encoding Übungen

### Übung  3.4 (Radix-16 kodieren)

Zuerst den String `2AHITS\n` in ASCII Code umwandeln und danach in Hex:

```sh
2 -> 50 -> 32
A -> 65 -> 41
H -> 72 -> 48
I -> 73 -> 49
T -> 84 -> 54
S -> 83 -> 53
\n -> 10 -> 0a
```

Jetzt in CyberChef mit `To Hex` überprüfen:
```sh
32 41 48 49 54 53 0d 0a
```
